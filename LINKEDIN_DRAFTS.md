🤖 Week 02 of the DevOps Micro Internship — Mastering Agentic AI

This week completely changed how I think about automation. Agentic AI is not just about running commands faster — it's about creating structured, safe, and reusable AI workflows.

Here's what I built:

• Claude Code CLI — Set up and experienced the Agentic Loop (Gather → Act → Verify) in real-time. Watching Claude read files, execute commands, and verify results showed me AI agents follow a structured, repeatable process.

• Custom Skills — Built reusable slash commands for infrastructure scaffolding, Terraform planning, deployment, security auditing, and cost estimation. Each skill has controlled tool permissions so it can't do more than it should.

• Specialized Subagents — Created Security Auditor, Cost Optimizer, and Terraform Writer subagents, each with focused instructions and appropriate model selection.

• MCP Integration — Connected Claude to GitHub for live repository access, enabling real-time code review and collaboration.

• Safety Hooks & Permissions — Implemented guardrails that prevent destructive actions and give the human final say. AI agents are powerful, but they need proper boundaries.

• Cross-Session Memory — Enabled context persistence so Claude remembers project decisions and conventions across sessions.

The biggest lesson: AI agents need structured instructions and safety guardrails to be truly effective in production environments. The human must always stay in the loop.

🔀 Week 04 of the DevOps Micro Internship — Git, GitHub & Version Control

This week I learned that Git is not just a save button — it's a time machine with safety rails.

Here's what I built:

📁 CodeTrack Project — Created and initialized a local Git repository, configured identity at both local and global levels, and tracked meaningful commits with clear messages.

🌿 Branching Workflow — Created a contact page on a feature branch, merged it cleanly, and experienced why atomic commits matter. When you need to roll back one change without losing another, focused commits save you.

🔄 Open-Source Collaboration — Forked, cloned, configured remotes, created a feature branch, synced with upstream, and opened a Pull Request — the real workflow used by millions of developers every day.

🛡️ AI-Assisted Git Safety Net — Built a real pre-commit hook that blocks commits containing hardcoded secrets and oversized files before they reach the repository. Then paired it with a Claude Code skill that drafts PR descriptions and flags subtle issues a fixed rule can't catch.

The key insight: Fixed-rule hooks catch what they're programmed to catch every time without fail. AI-assisted review catches nuanced issues — mixed changes, missing context, unclear intent. Together they provide defense in depth.

The human always stays in the loop. AI suggests, humans decide.
