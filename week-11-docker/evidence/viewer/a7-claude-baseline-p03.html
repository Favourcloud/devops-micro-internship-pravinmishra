 47  No `HEALTHCHECK` instruction is present in the image, and none was injected via Compose's 
     `healthcheck:` key. Without it, Docker marks the container as `healthy` by default the moment it 
     starts — a crashed or deadlocked app goes undetected and Compose will not restart it on its own.
 48  
 49  **Recommended Dockerfile fix:**
 50  
 51  ```dockerfile
 52  HEALTHCHECK --interval=30s --timeout=5s --start-period=10s --retries=3 \
 53    CMD wget -qO- http://localhost:3000/health || exit 1
 54  ```
 55  
 56  Adjust the port and path to match the actual application endpoint. `wget` is available on Alpine-based
      images; substitute `curl -f` if the base image carries curl instead.
