 40  ### Remaining limit: versioned tag vs. immutable digest
 41  
 42  The image check passes but carries this note: **`(mutable; digest preferred)`**. A tag like `:1.0.0` 
     is a human-readable pointer in the registry — it can be repointed to a different image layer without 
     warning. An immutable digest (`sha256:…`) is a cryptographic hash of the exact image manifest; it 
     cannot change. For production or supply-chain-sensitive deployments the Dockerfile `FROM` line should 
     pin to a digest:
 43  
 44  ```dockerfile
 45  # Mutable tag — passes this audit but still rebindable
 46  FROM node:20-alpine3.19
 47  
 48  # Immutable digest — strongest guarantee
 49  FROM node:20-alpine3.19@sha256:<full-digest-here>
 50  ```
 51  
 52  For the application image itself the Compose `image:` field or a private registry tag should similarly
      be frozen by digest if reproducibility is required.
