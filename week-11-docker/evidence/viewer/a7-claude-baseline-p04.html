 66  A **versioned tag** such as `node:22-alpine` pins to a named release but is still mutable in theory (a
      registry maintainer can re-push to that tag). An **immutable digest** such as:
 67  
 68  ```
 69  node:22-alpine@sha256:abc123...
 70  ```
 71
