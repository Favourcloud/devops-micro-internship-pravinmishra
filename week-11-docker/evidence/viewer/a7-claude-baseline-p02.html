 23  > `Container configured as root`
 24  
 25  The process inside the container runs as **UID 0 (root)**. If an attacker exploits the application, 
     they inherit root privileges inside the container. Combined with any volume mount or capability leak, 
     this can escalate to the host.
 26  
 27  **Recommended Dockerfile fix:**
 28  
 29  ```dockerfile
 30  # add after the npm install / build steps, before CMD
 31  RUN addgroup --system app && adduser --system --ingroup app app
 32  USER app
 33  ```
 34  
 35  Or, if the base image already ships a non-root user (e.g., `node:22-alpine` ships `node`):
 36  
 37  ```dockerfile
 38  USER node
 39  ```
